App install karo — phir seedha icon se khulega, browser ki zaroorat nahi.

Install kaise karein
  1. Chrome ka ⋮ menu kholo (upar right).
  2. Install app ya Add to Home screen dabao.
  3. Confirm karo — icon ban jayega.
Agar Install button kaam na kare, to neeche wale APK button se file download karke install kar lo.
